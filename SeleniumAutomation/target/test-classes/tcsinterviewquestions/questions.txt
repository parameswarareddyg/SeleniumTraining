Find element and find elements
findElement will return only one element and if not found in webpage throws no such element exception.
findElements will return List<WebElement> and if not found in webpage returns empty List.
Maximum Wait :
Selenium does not have a strict maximum wait limit technically,
but professionally we use optimized timeout values. 
Explicit waits are preferred because Selenium waits only until the condition is satisfied, 
improving framework stability and execution speed.

driver.close() and driver.quit() :
driver.close() close the current window/tab 
driver.quit() Closes all browser windows and ends WebDriver session

Syntax					XML path language							CSS styling syntax
Direction				Forward + backward traversal				Forward traversal only

Readability				Longer										Cleaner & shorter
